# 공유 링크 발급 가이드 (발행자용)

노션 견적서 DB에서 견적서를 작성하면, 클라이언트가 로그인 없이 웹에서 확인하고 PDF로 내려받을 수 있는 링크를 만들 수 있습니다. 이 문서는 발행자가 링크를 발급하는 절차를 설명합니다.

## 1. 발급 절차

1. 노션 견적서 DB(`invoices`)에 새 행(페이지)을 만듭니다.
2. 아래 속성을 모두 채웁니다.
   - `견적서 번호`, `클라이언트명`, `발행일`, `유효기간`
   - `항목`: 견적 항목(Items DB)을 연결합니다. 각 항목에는 `항목명`, `수량`, `단가`가 필요합니다.
3. `상태`를 `승인`으로 바꿉니다. `승인`이 아닌 값(`대기`, `거절` 등)은 임시 상태로 보고 링크를 열어도 내용을 보여주지 않습니다.
4. `유효기간`을 오늘 이후 날짜로 설정합니다. 유효기간 당일까지는 열리고, 다음 날부터 만료 안내가 나옵니다.
5. 아래 형식으로 링크를 만들어 클라이언트에게 전달합니다.

```
https://{서비스 주소}/estimate/{노션 페이지 ID}
```

예: `https://example.com/estimate/405e2e81-b8f1-803c-9fa2-fb8ed0057e8e`

- 페이지 ID는 하이픈이 있는 형식(`405e2e81-b8f1-803c-9fa2-fb8ed0057e8e`)과 없는 형식(`405e2e81b8f1803c9fa2fb8ed0057e8e`) 모두 쓸 수 있습니다.
- 금액(공급가액, 부가세 10%, 총액)은 항목의 수량과 단가로 웹에서 계산합니다. 노션의 `총 금액` 값은 화면과 PDF에 쓰이지 않습니다.
- 화면과 PDF의 발행자 이름과 연락처는 노션이 아니라 서버 환경변수 `ISSUER_NAME`, `ISSUER_CONTACT`에서 가져옵니다. 설정하지 않으면 기본값("예시 발행자")이 표시되므로 운영 전에 설정하세요.
- 노션에서 값을 고치면 웹에는 최대 1시간 이내에 반영됩니다.

## 1-1. 관리자 목록에서 링크 복사 (고도화)

노션 페이지 ID를 직접 찾지 않아도, 관리자 화면 `/admin/estimates`의 목록에서 링크를 복사할 수 있습니다. 관리자 비밀번호로 로그인한 뒤 사용합니다.

1. `/admin/login`에서 관리자 비밀번호로 로그인합니다.
2. 목록에서 해당 견적서 행의 **링크 복사** 버튼을 누릅니다. 클립보드에 `{기준 주소}/estimate/{노션 페이지 ID}` 형식의 링크가 복사됩니다. 기준 주소는 환경변수 `NEXT_PUBLIC_APP_URL`이고, 비어 있으면 지금 접속한 주소입니다.
3. 상태별 동작은 다음과 같습니다.
   - 승인: 바로 복사됩니다.
   - 만료됨: 복사되지만 만료됨 경고가 함께 표시됩니다. 클라이언트에게는 만료 안내가 보입니다.
   - 대기, 거절, 정보 누락: 버튼이 비활성화되고 이유가 표시됩니다.
4. 목록은 노션을 캐시 없이 읽으므로 노션에서 바꾼 상태가 새로고침하면 바로 보입니다. 공개 견적서 화면은 최대 1시간 캐시됩니다.

> 이 기능은 코드로 구현되었지만 운영 환경 배포와 운영 환경변수(`ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, `NEXT_PUBLIC_APP_URL`) 등록은 Task 025에서 사용자가 승인한 뒤 진행합니다.

## 2. 노션 페이지 ID 확인 방법

1. 노션에서 견적서 페이지를 엽니다.
2. 오른쪽 위의 `공유`(또는 `…` 메뉴)에서 `링크 복사`를 누릅니다.
3. 복사된 주소는 `https://www.notion.so/{제목}-{ID}` 또는 `https://www.notion.so/{ID}?v=…` 모양입니다. 주소 끝쪽의 **32자리 영문·숫자**가 페이지 ID입니다. `?` 뒤의 값은 포함하지 않습니다.
4. 이 32자리를 `/estimate/` 뒤에 붙입니다.

DB를 표 보기로 열었다면 행 옆의 `열기` 버튼으로 페이지를 연 뒤 같은 방법으로 복사합니다. 이 링크로는 노션 페이지 본문이 아니라 웹 뷰어 화면이 열립니다. 노션 주소 자체를 클라이언트에게 전달하지 않습니다.

## 3. 상황별 화면

| 상황                                              | 클라이언트에게 보이는 화면                                        |
| ------------------------------------------------- | ----------------------------------------------------------------- |
| `상태`가 `승인`이고 유효기간이 지나지 않음        | 견적서 상세와 `PDF 다운로드` 버튼                                 |
| `상태`가 `대기`, `거절` 등 `승인`이 아님 (임시)   | "아직 발행되지 않은 견적서입니다" 안내. 금액과 항목은 보이지 않음 |
| 유효기간이 지남                                   | "유효기간이 지난 견적서입니다" 안내. 금액과 항목은 보이지 않음    |
| 필수 값 누락 (견적서 번호, 클라이언트명, 날짜 등) | "견적서 정보를 표시할 수 없습니다" 안내                           |
| 링크의 ID가 틀렸거나 DB에 없는 페이지             | "견적서를 찾을 수 없습니다" (404) 화면과 홈으로 돌아가기 버튼     |
| 항목이 하나도 없음                                | 상세 화면에 "등록된 항목이 없습니다." 표시, 합계 0원              |
| 노션 요청 한도 초과                               | "요청이 많아 잠시 후 다시 시도해 주세요" 안내                     |
| 노션 연결 오류 (장애, 시간 초과)                  | "견적서를 불러오지 못했습니다" 화면과 `다시 시도` 버튼            |

## 4. 점검 체크리스트

- [ ] `상태`가 `승인`인가?
- [ ] `유효기간`이 오늘 이후인가?
- [ ] `견적서 번호`, `클라이언트명`, `발행일`이 채워져 있는가?
- [ ] 항목마다 `항목명`, `수량`, `단가`가 있는가?
- [ ] 노션 연동(Integration)이 견적서 DB와 항목 DB에 연결되어 있는가? 연결되지 않으면 "견적서를 찾을 수 없습니다"가 나옵니다.
- [ ] 링크를 시크릿 창에서 열어 로그인 없이 확인되는가?

## 5. 알아 둘 점

- 링크를 아는 사람은 누구나 견적서를 볼 수 있습니다. 링크는 추측하기 어려운 노션 페이지 ID이지만, 외부에 공개하지 말고 클라이언트에게만 전달하세요.
- 견적서 페이지는 검색 엔진에 노출되지 않도록 설정되어 있습니다(noindex).
- 링크를 더 이상 열고 싶지 않으면 `상태`를 `승인`이 아닌 값으로 바꾸거나 `유효기간`을 과거 날짜로 바꿉니다. 캐시 때문에 최대 1시간 뒤에 반영됩니다.
