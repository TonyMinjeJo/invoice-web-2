# Task 023: 목록에서 공유 링크 복사

## 명세

- 링크 형식 `{기준 주소}/estimate/{노션 페이지 ID(하이픈 포함)}`. 기준 주소는 `NEXT_PUBLIC_APP_URL`, 없으면 현재 origin(G4). `.env.example`에는 Task 020에서 이미 추가했다.
- `src/lib/estimate/share-link.ts`: 순수 함수 `buildShareLink`(끝 슬래시 제거)와 `getShareLinkPolicy`(승인 복사, 만료됨 복사+경고, 대기·거절·정보 누락 비활성+이유).
- `src/components/admin/copy-link-button.tsx`(`'use client'`): 복사 동작만. 성공 시 sonner 성공 토스트, 실패 시 실패 토스트와 선택 가능한 읽기 전용 링크 입력을 보여준다.
- `share-link-cell.tsx`(서버 컴포넌트)가 정책을 판정해 활성 버튼 또는 비활성 버튼+이유 문구를 렌더링한다.
- `src/lib/env.ts`: `NEXT_PUBLIC_APP_URL`의 빈 문자열을 미설정으로 처리(`.env.example`의 빈 값을 그대로 복사해도 앱이 죽지 않게).

## 변경 파일

- 추가: `src/lib/estimate/share-link.ts`, `src/components/admin/copy-link-button.tsx`
- 수정: `src/components/admin/share-link-cell.tsx`, `src/lib/env.ts`
