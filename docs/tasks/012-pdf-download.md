# Task 012: PDF 생성 및 다운로드 구현

## 목표

발행 상태 견적서를 `@react-pdf/renderer`로 PDF로 만들어 내려받게 한다. 한글은 Noto Sans KR로 표시한다.

## 변경 파일

| 파일                                              | 상태 | 내용                                                       |
| ------------------------------------------------- | ---- | ---------------------------------------------------------- |
| `src/components/pdf/estimate-document.tsx`        | 생성 | PDF 문서. `Quote`와 `calculate.ts` 결과만 받는다           |
| `src/app/estimate/[shareId]/pdf/route.ts`         | 생성 | Route Handler (`runtime = 'nodejs'`). 발행 상태만 PDF 생성 |
| `src/lib/pdf/register-fonts.ts`                   | 생성 | Noto Sans KR 등록, 한글 줄바꿈 허용                        |
| `src/components/estimate/pdf-download-button.tsx` | 생성 | 다운로드 버튼, 로딩과 실패 상태 표시                       |

## 설계 결정

- 폰트는 Noto Sans KR로 통일한다 (사용자 확정, Arial 불가). 라이선스 파일은 `src/lib/pdf/fonts`에 있다.
- 파일명은 `견적서_{견적번호}.pdf` 형식이다. 구형 클라이언트용 ASCII 이름(`estimate.pdf`)도 함께 준다.

## 실연결 검증 (2026-10-28, 개발 서버, Playwright, `INV-2026-001`)

| TC        | 결과 | 확인 내용                                                                                                      |
| --------- | ---- | -------------------------------------------------------------------------------------------------------------- |
| TC-012-01 | ✅   | PDF 경로 응답 200, `Content-Type: application/pdf`, `filename*=UTF-8''견적서_INV-2026-001.pdf`                 |
| TC-012-02 | ✅   | PDF 텍스트에서 추출한 금액 5,000,000 / 500,000 / 5,500,000이 화면 금액과 일치                                  |
| TC-012-05 | ✅   | 사용자가 PDF 파일을 열어 한글이 정상 표시됨을 직접 확인 (2026-10-28)                                           |
| TC-012-07 | 보류 | 임시 상태 PDF 차단은 PDF 경로가 404를 돌려주는 것으로 확인했으나(만료 상태 기준), 임시 상태 기준 확인은 미실행 |

## 미실행 TC

- TC-012-03 (PDF 생성 실패 시 안내), TC-012-04 (항목 50개 여러 페이지), TC-012-06 (모바일 탭 다운로드): 테스트 데이터 또는 장애 주입이 필요해 아직 실행하지 않았다.

## 확인 중 발견한 사항

- 개발 서버에서 `.next/cache/fetch-cache`가 남아 있을 때 PDF 경로가 이전 판정(만료)으로 404를 돌려주었다. 캐시를 비운 뒤 200으로 바뀌었다. (Task 011 참고)
- `pdftotext`는 PDF의 한글 라벨을 추출하지 못했다. 한글 확인은 사람이 PDF를 열어 확인하는 방식으로 했다.
