# Task 004: 견적 계산 로직 구현 (더미 데이터 기반)

## 목표

항목(수량 × 단가)으로부터 공급가액, 부가세(10%), 총액을 계산하는 순수 함수를 만들고, 더미 견적서 2~3종을 준비한다. 노션 호출과 화면 연결은 포함하지 않는다 (화면 연결은 Task 005에서 한다).

## 결정 사항

- 계산 함수는 `src/lib/estimate/calculate.ts`에 둔다. 외부 의존성이 없는 순수 함수다.
- 금액은 원 단위 정수로만 다룬다. 소수가 생기는 입력은 검증 단계에서 거부한다.
- **Q2 미확정**: 부가세 반올림은 ROADMAP2 임시 기본값(원 단위 정수, 부가세는 내림)을 적용한다. Q2가 확정되면 `calculate.ts` 한 곳만 고친다.
- 더미 데이터는 `src/lib/estimate/dummy-quotes.ts`에 둔다. Task 010에서 파일째 제거한다.
- 고객 정보는 가상의 이름만 쓴다 (실제 고객 정보 금지).
- 노션 `총 금액`(`notionTotalAmount`)은 계산에 쓰지 않는다.

## 계산 규칙

| 값        | 규칙                               |
| --------- | ---------------------------------- |
| 항목 금액 | `quantity × unitPrice`             |
| 공급가액  | 모든 항목 금액의 합                |
| 부가세    | `floor(공급가액 × 0.1)` (임시, Q2) |
| 총액      | 공급가액 + 부가세                  |

- 항목이 0개면 모든 값이 0이다.
- 계산은 `calculateSummary(items: QuoteItem[]): QuoteSummary`로 노출한다 (`QuoteSummary`는 `types.ts`에 이미 정의되어 있다).

- 음수, 소수, `NaN`이 들어오면 예외를 던지거나 검증에서 거부한다 (조용히 0 처리 금지)
