# Task 005: 견적서 상세 화면 UI 구현

## 목표

더미 견적서를 보여 주는 상세 화면을 만든다. 발행자·클라이언트 정보, 견적 번호, 발행일, 유효기간, 항목 표(모바일은 카드형), 합계 3줄, PDF 버튼 자리를 포함한다. PDF 동작은 Task 012에서 연결한다.

## 결정 사항

- 더미 조회는 `/estimate/[shareId]`에서 `dummy-quotes.ts`의 id로 찾는다. 이 조회는 Phase 2 전용이며 Task 010에서 노션 조회로 교체한다.
- 화면 문구의 "수신자"는 노션 속성 `클라이언트명`(`Quote.clientName`)을 가리킨다 (Task 003 매핑 기준).
- 발행자 정보는 고정 문구로 둔다 (노션 속성에 없음). 값은 임시 placeholder이며 Task 010 이전에 확정한다.
- 계산은 Task 004의 `calculateSummary`만 사용하고 화면에서 금액을 직접 계산하지 않는다.
- 상세 화면은 `status === 'draft'`이거나 찾을 수 없으면 Task 006의 예외 화면으로 분기한다.

## 수락 기준

- 상세 화면에 발행자, 클라이언트, 견적 번호, 발행일, 유효기간, 항목 표, 합계 3줄, PDF 버튼이 모두 보인다.
- 항목 표는 `<table>`로, 모바일에서는 같은 데이터를 카드 목록으로 보여 준다. 둘 중 하나만 화면에 노출된다.
- 긴 항목명은 줄바꿈되고 표가 넘치지 않는다.
- 390×844에서 `scrollWidth`가 `clientWidth`를 넘지 않는다.
- 금액은 천 단위 구분 기호와 "원"을 붙여 표시한다.

## 구현 단계

1. 더미 조회 함수와 `page.tsx` 분기 연결
2. 헤더, 항목 표/카드, 합계, 액션 컴포넌트 작성 (shadcn/ui Card, Table, Badge 사용)
3. 반응형 스타일 적용 (데스크톱 표, 모바일 카드 전환)
4. `npm run check-all`, `npm run build`
5. Playwright MCP로 TC-005-01~04 실행
