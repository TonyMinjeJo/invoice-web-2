# Task 022: 관리자 목록 실데이터 연결과 상태 표시

## 명세

- `src/app/admin/estimates/page.tsx`가 `listEstimates()` 결과를 서버 컴포넌트로 렌더링한다. 더미 파일(`dummy-list.ts`)은 제거했다.
- 상태 Badge는 텍스트로 구분한다: 승인, 대기, 거절, 만료됨, 정보 누락(`status-badge.tsx`, 색은 토큰만 사용).
- 연동 오류는 `error.tsx`(원본 메시지 없음), 요청 제한은 안내 문구(`role="alert"`)로 처리한다.
- 정렬은 노션 쿼리의 발행일 내림차순 고정. 검색·필터 없음. `export const dynamic = 'force-dynamic'`으로 캐시하지 않는다.
