# Task 011: 공유 링크 접근 제어 구현

## 목표

공유 식별자로 들어온 요청을 한 함수(`getPublishedQuote`)에서만 판정한다. 임시(대기) 견적서는 금액과 항목을 보여주지 않고, 유효기간이 지난 견적서는 만료 안내를 보여준다.

## 변경 파일

| 파일                                      | 상태 | 내용                                                                                        |
| ----------------------------------------- | ---- | ------------------------------------------------------------------------------------------- |
| `src/lib/notion/get-published-quote.ts`   | 생성 | 식별자 검사, 노션 조회, 임시 차단, 유효기간 판정, 캐시 (found/draft/expired/notFound/error) |
| `src/app/estimate/[shareId]/page.tsx`     | 수정 | 더미 경로 대신 `getPublishedQuote` 사용, `dummy-error` 분기 제거                            |
| `src/app/estimate/[shareId]/pdf/route.ts` | 생성 | 같은 함수를 사용하는 PDF 경로 (발행 상태만 PDF 생성)                                        |

## 설계 결정

- 상태 매핑: 노션 `상태` 옵션 `승인`을 발행(issued), `대기`와 `거절`을 임시(draft)로 본다. 사용자 확정 (노션에 `발행` 옵션이 없음).
- 유효기간 판정: `src/lib/estimate/availability.ts`를 재사용하고, 서울 기준 날짜로 비교한다.

## 확인 중 발견한 사항

- 조회 결과는 `unstable_cache`로 `.next/cache/fetch-cache`에 디스크 저장된다. 노션 데이터를 고쳐도 TTL(기본 3600초) 동안 이전 값이 나온다. 테스트 중에는 해당 캐시 폴더를 지우고 서버를 다시 띄워야 반영된다.
- 개발 서버 종료 후에도 3000 포트 프로세스가 남는 경우가 있어, 재시작 전에 포트 점유 여부를 확인해야 한다.
