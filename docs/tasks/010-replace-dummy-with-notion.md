# Task 010: 더미 데이터를 노션 데이터로 교체

## 목표

견적서 상세 페이지가 더미 데이터 대신 노션 데이터로 렌더링되게 하고, 캐싱(TTL 기본 3600초, 테스트 시 환경변수로 단축)을 적용한다. 더미 파일과 참조를 제거한다.

## 변경 파일

| 파일                                    | 상태 | 내용                                                                   |
| --------------------------------------- | ---- | ---------------------------------------------------------------------- |
| `src/lib/estimate/dummy-quotes.ts`      | 삭제 | 더미 견적서 데이터                                                     |
| `src/lib/notion/get-published-quote.ts` | 수정 | `unstable_cache` 기반 TTL 캐시 (`NOTION_CACHE_TTL_SECONDS`, 기본 3600) |
| `src/lib/env.ts`, `.env.example`        | 수정 | `NOTION_CACHE_TTL_SECONDS` 선택 항목 추가                              |

## 설계 결정

- 캐시 TTL 기본값은 Q5 확정값(1시간)이다. 테스트용 짧은 값은 환경변수로 받는다.
- 발행자 정보는 자리표시자 값을 그대로 쓴다 (`src/lib/estimate/issuer.ts`).

## 확인 중 발견한 사항

- 캐시 entry는 디스크(`.next/cache/fetch-cache`)에 남는다. 노션 값을 고쳐도 TTL 동안 이전 값이 보일 수 있으므로, 테스트 시에는 캐시 폴더를 지우고 서버를 다시 띄운다.
- 잘못된 DB ID일 때 서버 로그에는 오류 코드(`object_not_found`)와 식별자 앞 8자리만 남고, 화면과 브라우저 콘솔에는 원문이 나가지 않았다.
