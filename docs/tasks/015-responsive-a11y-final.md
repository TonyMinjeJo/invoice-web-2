## 테스트 환경

- TC-015-01, 02는 개발 서버, TC-015-03은 `npm run build` 후 `npm run start`(최종 빌드)에서 실행했다.
- 노션 데이터는 읽기만 했다. 임시(대기)와 만료 상태 견적서는 현재 노션에 없고, 만들려면 데이터를 바꿔야 하므로 이번에는 만들지 않았다.
