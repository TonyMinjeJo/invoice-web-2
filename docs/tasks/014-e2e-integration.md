# Task 014: E2E 통합 테스트

## 목표

공유 링크 접속, 견적 확인, PDF 다운로드까지의 전체 사용자 플로우를 Playwright MCP로 검증한다. 존재하지 않는 링크, 항목 0개, 특수문자 항목명 같은 예외와 경계 상황도 확인한다.

## 변경 파일

| 파일                                | 상태 | 내용                                     |
| ----------------------------------- | ---- | ---------------------------------------- |
| `docs/tasks/014-e2e-integration.md` | 신규 | 테스트 결과 기록. 운영 코드 변경은 없다. |

## 테스트 환경

- 개발 서버(`npm run dev`, Turbopack), 기본 설정(`NOTION_BASE_URL`, `NOTION_CACHE_TTL_SECONDS` 미설정), 실제 노션 DB 읽기 전용.
- 노션 테스트 데이터는 생성, 수정, 삭제하지 않았다.
- 노션 호출은 서버에서 일어나므로 브라우저 네트워크에서는 PDF 라우트(`/estimate/[shareId]/pdf`)의 상태 코드와 Content-Type만 확인했다.
- PDF 파일은 `.playwright-mcp/` 폴더(gitignore됨)에 내려받았다.

## 확인 중 발견한 사항

- 콘솔의 `estimate_invalid`, `estimate_load_failed` 로그와 노션 `object_not_found` 경고는 이전 Task의 장애·누락 시나리오 기록이다. 이번 실행에서 새로 생긴 앱 오류는 없다.
- 번호가 비어 있는 `407e2e81-b8f1-8114-a445-fa1274ba9f1f`는 "견적서 정보를 표시할 수 없습니다" 안내가 나오고(HTTP 200), 서버 로그에 `estimate_invalid`가 남는다. 이는 Task 009·011에서 정한 동작이다.
- 구현 버그는 발견하지 못했다.
