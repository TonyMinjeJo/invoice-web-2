# MVP 이후 기능 목록 (Q8)

MVP 범위는 "노션에 입력한 견적서를 공유 링크로 조회하고 PDF로 내려받기"입니다. 아래 기능은 MVP에 포함하지 않았고, **이후 버전에서 검토**할 후보입니다. 확정된 계획이 아니며, 필요성과 우선순위는 사용해 본 뒤 정합니다.

| 번호 | 후보 기능             | 설명                                                                                                                                                            | 검토 시 고려할 점                                           |
| ---- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 1    | 견적 승인             | 클라이언트가 웹에서 견적을 승인하거나 거절하고, 결과를 노션 `상태`에 반영한다.                                                                                  | 현재는 노션 읽기 전용이라 쓰기 권한과 본인 확인이 필요하다. |
| 2    | 이메일 발송           | 발행자가 클라이언트에게 공유 링크를 이메일로 보낸다.                                                                                                            | 발송 서비스 선택, 발송 이력, 스팸 방지                      |
| 3    | 발행자 관리 화면      | 견적서 목록, 상태 확인, 링크 복사를 한곳에서 한다. **고도화에서 구현함 (Task 019~023, 읽기 전용, 단일 비밀번호 로그인). 운영 배포 완료 (Task 025, 2026-10-28)** | 편집·삭제·승인 기능은 계속 제외한다 (R-02)                  |
| 4    | 읽음 확인             | 클라이언트가 링크를 열어 본 시점을 발행자에게 알린다.                                                                                                           | 개인정보와 조회 기록 보관 정책                              |
| 5    | 링크 만료와 접근 제한 | 링크 비활성화, 접근 비밀번호, 짧은 공유용 주소(slug)를 지원한다.                                                                                                | 노션 페이지 ID 대신 공유 식별자를 쓰는 방식 (Q1 재검토)     |
| 6    | 발행자 정보 설정      | 발행자 이름, 연락처, 로고를 노션이나 설정에서 관리한다.                                                                                                         | 현재는 환경변수(`ISSUER_NAME`, `ISSUER_CONTACT`)를 쓴다     |
| 7    | PDF 디자인 확장       | 로고, 도장, 약관 문구, 다국어를 넣는다.                                                                                                                         | 폰트 용량, 생성 시간                                        |
| 8    | 다중 통화와 세율 설정 | 원화 외 통화와 부가세 10% 외 세율을 지원한다.                                                                                                                   | 반올림 규칙(Q2 재검토)                                      |
| 9    | 캐시 즉시 갱신        | 노션 수정 즉시 웹에 반영한다(웹훅 또는 수동 갱신).                                                                                                              | 현재는 최대 1시간 지연을 허용한다 (Q5)                      |
| 10   | 모니터링과 알림       | 노션 연동 오류, 요청 제한을 감지해 발행자에게 알린다.                                                                                                           | 로그 수집 도구, 개인정보가 로그에 남지 않도록 주의          |
