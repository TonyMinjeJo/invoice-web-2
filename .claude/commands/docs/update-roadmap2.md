# Claude 명령어: Update Roadmap2

`docs/ROADMAP2.md`에서 완료된 Task를 ✅로 표시하고, 테스트 체크리스트와 Phase 상태를 갱신합니다.

## 사용법

```
/update-roadmap2
/update-roadmap2 004
/update-roadmap2 004,005
```

## 프로세스

1. `docs/ROADMAP2.md` 읽기
2. 인자(`$ARGUMENTS`)가 있으면 그 Task 번호를 쓴다. 없으면 미완료 Task 목록(`- **Task`로 시작하고 ✅가 없는 항목)을 보여주고 "어떤 Task를 완료했나요? (예: 004 또는 004,005)"를 묻는다.
3. 각 Task의 `docs/tasks/{번호}-*.md` 파일 "결과 기록" 섹션을 읽어 TC별 ✅ / ❌ / 보류를 확인한다.
4. 아래 "완료 판정 규칙"을 적용한다.
5. Task 제목, TC 체크박스, Phase 제목, Phase DoD, 하단 로드맵 체크리스트를 "업데이트 규칙"대로 갱신한다.
6. 변경 내용과 진행 상황을 출력한다.

## 완료 판정 규칙

- 정상·예외·경계 TC가 모두 ✅여야 Task를 완료로 표시한다. (ROADMAP2 워크플로우 112행)
- 결과 기록에 ❌ 또는 보류가 하나라도 있으면 해당 TC는 `[ ]`로 둔다. Task 제목은 자동으로 완료 표시하지 않고 사용자에게 다시 확인한다.
- `npm run check-all`, `npm run build` 통과 여부를 확인한다. 확인되지 않았으면 완료로 표시하지 않는다.
- 작업 파일이 없으면 TC는 건드리지 않는다. Task 제목은 사용자가 명시적으로 확인한 경우에만 표시한다.

## 업데이트 규칙

### Task 제목

- Before: `- **Task 004: 견적 계산 로직 구현 (더미 데이터 기반)**`
- After: `- ✅ **Task 004: 견적 계산 로직 구현 (더미 데이터 기반)**`
- 이미 `- ✅ **Task`로 시작하면 건너뛴다.

### 하위 항목

- 하위 불릿에는 ✅를 붙이지 않는다. 완료 여부는 TC 체크박스로만 표시한다.

### 테스트 체크리스트

- Before: `  - [ ] TC-004-01 [정상] ...`
- After: `  - [x] TC-004-01 [정상] ...`
- ✅로 확인된 TC만 `[x]`로 바꾼다.

### Phase 제목

- 해당 Phase의 모든 Task에 ✅가 있으면 `### Phase N: 제목` → `### Phase N: 제목 ✅`
- 이미 ✅가 있으면 건너뛴다.

### Phase DoD

- `**Phase N 완료 기준 (DoD)**` 아래 불릿 중 조건이 충족된 것만 `- ✅ ...`로 바꾼다.
- `npm run check-all`, `npm run build` 항목은 사용자 확인 후에만 바꾼다.

### 하단 로드맵 체크리스트 (`## 로드맵 체크리스트`)

- Phase 완료 시 대응 항목만 `[x]`로 바꾼다.
  - Phase 1 → "Phase 1에서 라우트와 타입 골격이..."
  - Phase 2 → "Phase 2에서 더미 데이터로..."
  - Phase 3 → "Phase 3에서 노션 연동과 PDF가..."
- 그 외 항목(전제 반영, 시나리오 형식, 미결정 Q 확정 등)은 판단이 필요하므로 건드리지 않고 목록만 보고한다.

## 건드리지 않는 영역

- 미결정 사항(Q1~Q8) 표
- 기술 스택, 리스크 및 대응, 비기능 요구사항
- 개발 워크플로우와 테스트 실행 절차 본문
- 날짜, 진행률 줄 (ROADMAP2에는 해당 줄이 없으므로 추가하지 않는다)

## 출력 형식

```
체크한 Task: 004 (TC 6/6 ✅)
보류 TC: TC-004-05 (Q2 반올림 규칙 미확정)
Phase 상태: Phase 2 진행 중 (004, 005 완료 / 17개 중 N개)
완료: N/17 Tasks
```

## 주의사항

- Task 번호는 3자리 숫자(001, 002, ...)를 쓴다.
- 여러 Task를 한 번에 처리할 수 있다 (예: 004,005,006).
- 이미 ✅인 Task는 건너뛴다.
- 완료 처리 후에는 중단하고 추가 지시를 기다린다. (ROADMAP2 워크플로우 58행)
